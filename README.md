# My Business Card

A minimal personal business card webpage built with HTML and CSS.

This repository contains a simple, responsive single-page business card intended as a small portfolio piece or learning project. It demonstrates a compact layout with a profile image, contact details, and social links.

How to view
- Open `index.html` in a web browser, or serve the folder with any static server.

Highlights
- Clean, single-file HTML/CSS structure
- Responsive card layout suitable for mobile and desktop
- Easy to customize: update `index.html` and `styles.css`

Technologies
- HTML5
- CSS3

Notes
- Consider adjusting colors and contrast for accessibility.
- Fix small typos in `styles.css` (e.g. `bordrer-box` → `border-box`) to ensure consistent layout.

Created by the project owner — feel free to customize for your portfolio.
